# Apsolut HI-FI

Web stranica tvrtke Apsolut HI-FI d.o.o. iz Rijeke — prodaja, montaža i servis
audio sustava, profesionalnog ozvučenja, alarma i videonadzora.

Statična stranica: čisti HTML, CSS i JavaScript, bez sustava za upravljanje
sadržajem, baze i vanjskih biblioteka.

## Struktura

```
index.html            početna
autoakustika.html     autoakustika, auto oprema, marine
hi-fi.html            Audio/Video HI-FI sustavi
profesionalni.html    profesionalni audio/video
zastita.html          zaštita objekta
style.css             izgled svih stranica
script.js             izbornik, galerija, radno vrijeme
images/               slike galerije
```

## Pokretanje

Otvorite `index.html` u pregledniku. Nema koraka izgradnje.

Za lokalni poslužitelj:

```bash
python3 -m http.server 8000
```

## Objava

Sve datoteke idu u glavnu mapu poslužitelja, uz `images` pokraj `index.html`.
